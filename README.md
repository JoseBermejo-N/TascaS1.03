# 🐘 PHP Arrays & Array Functions
Welcome to my PHP learning repository! This space is dedicated to collecting practical exercises, code challenges, and core array manipulation concepts that I develop as I progress through my training by ITAcademy.

## 🚀 Development Environment
- **PHP** (Version 8.2.12)
- **Editor:** Visual Studio Code
- **Recommended Extension:** PHP Server (or whichever extension you use to run them)

## 📂 Repository Structure
The project is organized by topics for easy navigation:

- **nivel1/** : Basic array operations.
- **nivel2/** : Advanced comparisons and operations
- **nivel3/** : Functional programming.

## 🛠️ How to Run This Project
If you want to test these exercises in your local environment using Visual Studio Code, follow these steps:

1. **Clone this repository:** `https://github.com/JoseBermejo-N/TascaS1.03.git
2. **Open the folder in your editor:** Open Visual Studio Code, go to File -> Open Folder, and select the cloned repository folder.
3. **Run the files:**
   - Open any `.php` file.
   - Right-click inside the editor and select "Run code".
